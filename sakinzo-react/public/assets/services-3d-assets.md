# Homepage service artwork

Seven original illustrations generated with the built-in `image_gen` tool on
2026-11-01. The user's blue 3D technology reference informed the visual style.
These images belong to the homepage service accordion; service-page hero images
are separate assets.

Every scene is saved in this directory as a 640 × 480 and 1200 × 900 WebP,
quality 84. They are loaded through responsive `picture` sources. The original
generated PNGs remain in the Codex generated-images directory. No existing image
was replaced. No external API key or generation CLI was used.

## Final prompt set

Each image used the shared specification below followed by its subject prompt.

### Shared specification

Use case: stylized-concept. Asset type: production website service illustration, wide 4:3 composition. Premium polished 3D isometric technology illustration in a cohesive Sakinzo brand style: luminous ice-blue / very pale periwinkle background, cobalt blue and navy devices, white frosted surfaces, soft studio illumination, realistic soft shadows, rounded edges, tasteful glossy details, clean sophisticated visual hierarchy. The image fills a rectangular website panel next to service descriptions. Keep main objects large, clearly identifiable and fully inside frame with 7% breathing room. Not a website screenshot: one beautiful cohesive rendered scene. No readable text, no letters, no labels, no brand logos, no watermarks; tiny abstract interface lines and charts are fine. Avoid overly busy decoration.

### Web and mobile

Subject: a navy laptop with a split abstract code editor and polished responsive website preview, a beautiful smartphone standing beside it showing the matching mobile application, a glossy blue upload cloud in the foreground and a small rocket suggesting launch. Floating rounded feature tiles with code brackets and simple UI symbols. Clearly represents custom web and mobile app development.

### DevOps

Subject: a large elegant blue cloud hovering above three connected server stacks, a luminous continuous-delivery infinity loop encircling the scene, build/test/deploy represented by connected minimal rounded tiles with a gear, a check mark and a small launch rocket. A small observability monitor with clean graph lines. Clearly represents cloud infrastructure, automated CI/CD and monitoring.

### Architecture

Subject: an elegant three-tier software architecture rendered as a layered 3D system: front-end screen blocks at the top, a central API / services hub as a floating blue cube cluster, database cylinders at the bottom, all linked by precise luminous blue connectors. A faint blueprint sheet on the base and modular frosted blocks imply thoughtful system planning. Clearly represents scalable software architecture.

### PoC, prototype and MVP

Subject: three successive product stages arranged from left to right on a single continuous platform: a simple wireframe on a frosted board, an interactive phone prototype in the middle, and a polished launched app beside a small glossy blue rocket on the right. Connected by subtle blue progress paths and small check marks. The three stages grow in finish and maturity. Clearly represents proof of concept, prototype and minimum viable product validation.

### Testing

Subject: a laptop displaying an abstract test dashboard with green and blue successful check marks, a large beautiful magnifying glass inspecting a small code window in the foreground, a frosted checklist panel, and a glossy cobalt protective shield with a check. Small orderly test nodes and a clean performance graph. Clearly represents software quality assurance, manual/automated testing, performance and security.

### UX/UI

Subject: a large floating design canvas with attractive component cards, responsive page layouts and a coherent blue / violet swatch palette, a polished smartphone app mockup in front, a glossy blue pen tool and cursor, and a small wireframe board. Tasteful connecting prototype curves. Clearly represents user research, interaction design and polished user interfaces.

### Business analysis

Subject: a sophisticated analyst workstation scene without people: a floating strategy board with a clear blue product roadmap, connected requirement cards, a dashboard screen with ascending bar charts and a small pie chart, a glossy magnifying glass and target with an arrow. Beautiful frosted surfaces and navy frames. Clearly represents business analysis, requirements discovery and product strategy.
